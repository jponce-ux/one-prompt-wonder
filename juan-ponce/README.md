# Juan Ponce TODO MVP

This MVP is a no-login TODO web app stored entirely in browser `localStorage`.

## Run Locally

```sh
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

## Validate

1. Add two todos.
2. Complete one todo.
3. Switch between All, Active, and Completed filters.
4. Refresh the browser and confirm todos persist.
5. Delete one todo and confirm it stays deleted after refresh.

## Build

```sh
cd frontend
npm run build
```
