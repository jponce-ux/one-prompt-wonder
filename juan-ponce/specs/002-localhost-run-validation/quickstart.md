# Quickstart: Localhost Run Validation

## Install And Launch

```sh
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

## Expected Result

The TODO app loads with an input, Add button, filter controls, counts, and an empty-state message.

## Manual MVP Check

1. Add two todos.
2. Complete one todo.
3. Confirm All, Active, and Completed filters show the right items.
4. Refresh the browser and confirm todos persist.
5. Delete one todo and confirm it does not return after refresh.

## Build

```sh
cd frontend
npm run build
```
