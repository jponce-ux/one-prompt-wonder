# Quickstart: TODO LocalStorage App

## Run Locally

```sh
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173`.

## Manual Validation

1. Add a todo named `Buy milk`; it appears as active.
2. Mark it complete; completed count increases.
3. Switch between All, Active, and Completed filters.
4. Refresh the browser; the todo remains.
5. Delete the todo; it disappears and stays deleted after refresh.

## Build Check

```sh
cd frontend
npm run build
```
