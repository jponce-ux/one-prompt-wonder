# Quickstart

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Validate

```bash
cd frontend
npm run build
```

Check the hero, all four navigation destinations, both carousel controls, the mobile menu near 375px width, and the complete page near 1440px width. Confirm the browser console has no runtime errors and the page has no unintended horizontal scrollbar.
